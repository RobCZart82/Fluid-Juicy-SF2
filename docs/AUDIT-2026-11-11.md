## Findings and implementation

| ID | Priority | Trigger and baseline evidence | Change |
| --- | --- | --- | --- |
| B01 | P2 | An ascending table header uses DataSorter with result > 0, placing larger values first. Repopulation also clears the header sort choice. See Source/TableComponent.cpp, sortOrderChanged, repopulateTable and DataSorter. | Correct the comparator, initialize the number header consistently, and retain the order when rebuilding rows. Regression selects the first row in both directions on numeric and natural-name columns. |
| B02 | P2 | processBlock forwards GM System On to FluidSynth without reading back reset selection or sound controllers. After program 1 / attack 112, the engine resets while host queries, sliders and saved parameters retain earlier values. See Source/FluidSynthModel.cpp, SysEx branch and applyControls. | Read sound controls and selection back after a successfully handled SysEx. Regression sends GM System On and verifies program 0 plus attack 64 in public state. |
| B03 | P2 | prepareFont falls to the first global preset if the requested program is absent. Replacing bank 8/program 1 with a bank containing 8/0 and 8/2 selects bank 0, contrary to the documented same-bank fallback. | Search the requested bank before global fallback. Regression checks the committed bank/program and actual 880 Hz rendered audio. |
| B04 | P2 | Manual row selection leaves displayedPreset stale. If MIDI changes back to that cached program before the next timer tick, the timer skips the refresh and highlights the wrong row. The extended ordering/worker regression reproduced this on local Windows and Apple Silicon CI. | Update the displayed selection cache when the selected row changes. Retain the worker isolation and eventual-refresh assertions. |
