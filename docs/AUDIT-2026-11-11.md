## Findings and implementation

| ID | Priority | Trigger and baseline evidence | Change |

| B02 | P2 | processBlock forwards GM System On to FluidSynth without reading back reset selection or sound controllers. After program 1 / attack 112, the engine resets while host queries, sliders and saved parameters retain earlier values. See Source/FluidSynthModel.cpp, SysEx branch and applyControls. | Read sound controls and selection back after a successfully handled SysEx. | B03 | P2 | prepareFont falls to the first global preset if the requested program is absent. Replacing bank 8/program 1 with a bank containing 8/0 and 8/2 selects bank 0, contrary to the documented same-bank fallback. | Search the requested bank before global fallback. Regression checks the committed bank/program and actual 880 Hz rendered audio. |

The corrections use the existing parameter IDs and XML state representation.
